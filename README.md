# সহজে (Sohoje)

বাংলাদেশের ১ম থেকে ১২শ শ্রেণির শিক্ষার্থীদের জন্য বাংলা ভাষায় শ্রেণি- ও বিষয়ভিত্তিক প্রশ্ন-উত্তরের ওয়েবসাইট।

## চালানোর নিয়ম

কোনো সার্ভার বা ইনস্টলেশন লাগে না। শুধু `index.html` ব্রাউজারে খুললেই হবে।
লোকাল সার্ভারে চালাতে চাইলে (ঐচ্ছিক):

```bash
python3 -m http.server 8000
# তারপর ব্রাউজারে: http://localhost:8000
```

## কাঠামো

```
index.html      → মূল পাতা
styles.css      → ডিজাইন
app.js          → রাউটিং, রেন্ডারিং ও খোঁজার লজিক
data/class-N.js → প্রতিটি শ্রেণির প্রশ্ন-উত্তর (N = ১ থেকে ১২)
```

সাইটের পাতাগুলো hash রাউটিং দিয়ে কাজ করে:
`#/` (হোম) → `#/class/9` (শ্রেণি) → `#/class/9/physics` (বিষয়) → `#/search/...` (খোঁজা)।

## নতুন প্রশ্ন-উত্তর যোগ করা

সংশ্লিষ্ট শ্রেণির ফাইল (যেমন `data/class-9.js`) খুলে অধ্যায়ের `qa` তালিকায়
নতুন একটি আইটেম যোগ করুন:

```js
{ q: 'তোমার প্রশ্ন এখানে?', a: 'উত্তর এখানে।' }
```

### নতুন অধ্যায় যোগ করা

বিষয়ের `chapters` তালিকায়:

```js
{ title: 'অধ্যায়ের নাম', qa: [ { q: '...', a: '...' } ] }
```

### নতুন বিষয় যোগ করা

শ্রেণির `subjects` তালিকায়:

```js
{ id: 'unique-id', name: 'বিষয়ের নাম', icon: '📗', chapters: [ ... ] }
```

> নোট: প্রতিটি শ্রেণির ভেতরে `subject`-এর `id` অনন্য (unique) হতে হবে।
> কোনো ডেটাবেজ নেই — সবকিছু সাধারণ JavaScript ফাইল, তাই সম্পাদনা করা সহজ।
